# GitHub Copilot CLI Integration

The Mem0 plugin for GitHub Copilot CLI allows your agent to remember context across sessions.

## Installation

Install the plugin natively:

```bash
mem0 install copilot
```

## Usage

Mem0 seamlessly injects context into your Copilot CLI sessions and extracts new knowledge in the background when the session ends.
