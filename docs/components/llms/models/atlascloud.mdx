[Atlas Cloud](https://atlascloud.ai) serves many open models (DeepSeek, Qwen, Kimi, GLM and more) behind one OpenAI-compatible endpoint.

To use Atlas Cloud LLM models, you have to set the `ATLASCLOUD_API_KEY` environment variable. You can create a key from the [API keys page](https://atlascloud.ai/docs/api-keys). You can also optionally set `ATLASCLOUD_API_BASE` if you need to use a different API endpoint (defaults to `https://api.atlascloud.ai/v1`).

## Usage

<CodeGroup>
```python Python
import os
from mem0 import Memory

os.environ["ATLASCLOUD_API_KEY"] = "your-api-key"
os.environ["OPENAI_API_KEY"] = "your-api-key" # for embedder model

config = {
    "llm": {
        "provider": "atlascloud",
        "config": {
            "model": "deepseek-ai/DeepSeek-V3.1-Terminus",  # default model
            "temperature": 0.2,
            "max_tokens": 2000,
            "top_p": 1.0
        }
    }
}

m = Memory.from_config(config)
messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about thriller movies? They can be quite engaging."},
    {"role": "user", "content": "I'm not a big fan of thriller movies but I love sci-fi movies."},
    {"role": "assistant", "content": "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future."}
]
m.add(messages, user_id="alice", metadata={"category": "movies"})
```

```typescript TypeScript
import { Memory } from 'mem0ai/oss';

const config = {
  llm: {
    provider: 'atlascloud',
    config: {
      apiKey: process.env.ATLASCLOUD_API_KEY || '',
      model: 'deepseek-ai/DeepSeek-V3.1-Terminus',
      temperature: 0.2,
      maxTokens: 2000,
      topP: 1.0,
    },
  },
};
const memory = new Memory(config);
const messages = [
  { role: "user", content: "I'm planning to watch a movie tonight. Any recommendations?" },
  { role: "assistant", content: "How about thriller movies? They can be quite engaging." },
  { role: "user", content: "I'm not a big fan of thriller movies but I love sci-fi movies." },
  { role: "assistant", content: "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future." },
];
await memory.add(messages, { userId: 'alice', metadata: { category: 'movies' } });
```

</CodeGroup>

The full model catalog is available from the gateway's public `GET /v1/models` endpoint, and model ids take the `vendor/model` form (for example `Qwen/Qwen3-235B-A22B-Instruct-2507`).

You can also configure the API base URL in the config:

<CodeGroup>
```python Python
config = {
    "llm": {
        "provider": "atlascloud",
        "config": {
            "model": "deepseek-ai/DeepSeek-V3.1-Terminus",
            "atlascloud_base_url": "https://your-custom-endpoint.com",
            "api_key": "your-api-key"  # alternatively to using environment variable
        }
    }
}
```

```typescript TypeScript
const config = {
  llm: {
    provider: 'atlascloud',
    config: {
      model: 'deepseek-ai/DeepSeek-V3.1-Terminus',
      baseURL: 'https://your-custom-endpoint.com',
      apiKey: 'your-api-key', // alternatively to using the environment variable
    },
  },
};
```
</CodeGroup>
