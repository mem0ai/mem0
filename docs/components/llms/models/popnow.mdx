[PopNow](https://popnow.ai/api) is a pay-as-you-go API that serves Claude, GPT, Gemini, DeepSeek, Kimi and other chat models through one OpenAI-compatible endpoint. Mem0 connects to it with the `openai` provider by setting `openai_base_url`, so there is nothing extra to install.

Create an API key in the [PopNow API console](https://popnow.ai/api/console/keys) and add funds to your API balance. Model IDs follow the `<lab>/<model>/chat` format; the [PopNow chat API docs](https://popnow.ai/docs/chat) list every model.

## Usage

```python
import os
from mem0 import Memory

os.environ["OPENAI_API_KEY"] = "your-api-key" # used for embedding model

config = {
    "llm": {
        "provider": "openai",
        "config": {
            "model": "anthropic/claude-sonnet-5.5/chat",
            "api_key": os.environ.get("POPNOW_API_KEY"),
            "openai_base_url": "https://api.popnow.ai/v1",
            "temperature": 0.2,
            "max_tokens": 2000,
        }
    }
}

m = Memory.from_config(config)
messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about thriller movies? They can be quite engaging."},
    {"role": "user", "content": "I'm not a big fan of thriller movies but I love sci-fi movies."},
    {"role": "assistant", "content": "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future."}
]
m.add(messages, user_id="alice", metadata={"category": "movies"})
```

<Note>
  Leave `OPENROUTER_API_KEY` unset when you use this configuration. If it is set, the `openai` provider sends requests to OpenRouter instead of `openai_base_url`.
</Note>
