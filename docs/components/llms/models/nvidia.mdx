---
title: NVIDIA
description: "Configure NVIDIA as an LLM provider in Mem0 with API key setup and optional custom endpoint configuration."
---

To use NVIDIA LLM models, you have to set the `NVIDIA_API_KEY` environment variable. You can also optionally set `NVIDIA_API_BASE` if you need to use a different API endpoint (defaults to `https://integrate.api.nvidia.com/v1`).

## Usage

<CodeGroup>
```python Python
import os
from mem0 import Memory

os.environ["NVIDIA_API_KEY"] = "your-api-key"
os.environ["OPENAI_API_KEY"] = "your-api-key" # for embedder model

config = {
    "llm": {
        "provider": "nvidia",
        "config": {
            "model": "meta/llama-3.1-8b-instruct",  # default model
            "temperature": 0.2,
            "max_tokens": 2000,
            "top_p": 1.0
        }
    }
}

m = Memory.from_config(config)
messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about thriller movies? They can be quite engaging."},
    {"role": "user", "content": "I'm not a big fan of thriller movies but I love sci-fi movies."},
    {"role": "assistant", "content": "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future."}
]
m.add(messages, user_id="alice", metadata={"category": "movies"})
```

```typescript TypeScript
import { Memory } from 'mem0ai/oss';

const config = {
  llm: {
    provider: 'nvidia',
    config: {
      apiKey: process.env.NVIDIA_API_KEY || '',
      model: 'meta/llama-3.1-8b-instruct',
      temperature: 0.2,
      maxTokens: 2000,
      topP: 1.0,
    },
  },
};
const memory = new Memory(config);
const messages = [
  { role: "user", content: "I'm planning to watch a movie tonight. Any recommendations?" },
  { role: "assistant", content: "How about thriller movies? They can be quite engaging." },
  { role: "user", content: "I'm not a big fan of thriller movies but I love sci-fi movies." },
  { role: "assistant", content: "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future." },
];
await memory.add(messages, { userId: 'alice', metadata: { category: 'movies' } });
```

</CodeGroup>

You can also configure the API base URL in the config:

<CodeGroup>
```python Python
config = {
    "llm": {
        "provider": "nvidia",
        "config": {
            "model": "meta/llama-3.1-8b-instruct",
            "nvidia_base_url": "https://your-custom-endpoint.com",
            "api_key": "your-api-key"  # alternatively to using environment variable
        }
    }
}
```

```typescript TypeScript
const config = {
  llm: {
    provider: 'nvidia',
    config: {
      model: 'meta/llama-3.1-8b-instruct',
      baseURL: 'https://your-custom-endpoint.com',
      apiKey: 'your-api-key', // alternatively to using the environment variable
    },
  },
};
```
</CodeGroup>
