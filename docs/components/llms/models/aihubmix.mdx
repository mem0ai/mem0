Set `AIHUBMIX_API_KEY` in your environment. This provider uses the OpenAI-compatible chat completions endpoint; choose a model that supports the chat and tool-calling features your memory workflow needs.

## Usage

```python
import os
from mem0 import Memory

# AIHUBMIX_API_KEY must be set in the environment before running this example.
assert os.environ.get("AIHUBMIX_API_KEY"), "Set AIHUBMIX_API_KEY"

memory = Memory.from_config({
    "llm": {
        "provider": "aihubmix",
        "config": {"model": "gpt-6.1-terra"},
    },
    "embedder": {
        "provider": "aihubmix",
        "config": {"model": "embed-v-4-0"},
    },
    "vector_store": {
        "provider": "qdrant",
        "config": {"collection_name": "aihubmix_memories", "embedding_model_dims": 1536},
    },
})

memory.add("I prefer science fiction films.", user_id="alice")
results = memory.search("What movies do I like?", filters={"user_id": "alice"})
print(results)
```

## Configuration

| Parameter | Default | Description |
| --- | --- | --- |
| `model` | `gpt-6.1-terra` | AIHubMix chat model identifier. |
| `api_key` | `AIHUBMIX_API_KEY` | Explicit key takes precedence over the environment variable. |
| `aihubmix_base_url` | `AIHUBMIX_BASE_URL` or `https://aihubmix.com/v1` | Explicit URL takes precedence over the environment variable. |

This is an OSS Python provider. It does not use `OPENAI_API_KEY` or `OPENROUTER_API_KEY`. Other common LLM options such as `temperature` and `max_tokens` follow the [LLM configuration](../config) settings.
