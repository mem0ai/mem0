With BYOK, memory extraction runs on a model you choose, billed to your own key. On [LoCoMo](https://github.com/snap-research/locomo), a public benchmark of 10 long conversations and 1,540 questions about them, we tested the most used, most capable and cheapest well-known models that work with BYOK, open-weight and closed. The results below show how accurate each model's memories are, what they cost and how long extraction takes.

## Which model to use

Each pick serves a different goal: **Best value** balances accuracy and price, **Best under $1** is the most accurate model under $1 per 1,000 add requests and **Best quality** the highest accuracy.

## Set up BYOK

1. As an organization owner, open **Settings → BYOK** in the [Mem0 dashboard](https://app.mem0.ai/dashboard/settings?tab=org-llm).
2. Pick a provider: OpenAI, Anthropic, OpenRouter or Azure OpenAI.
3. Paste your API key and enter the model. On OpenRouter, use the model's full ID, such as `deepseek/deepseek-v4.1-flash`. Azure OpenAI also needs your endpoint URL and deployment name.
4. Click **Save provider**. Mem0 extracts your memories with that model from then on. **Disable provider** switches back to Mem0's default model.

## How we tested

- Every model took the same test, and only the model extracting memories changed.
- Accuracy is the share of LoCoMo's questions answered correctly from each model's memories, graded against LoCoMo's reference answers and averaged over two runs.
- Cost is estimated from each model's calls, per 1,000 add requests of about 8 messages each.
- Latency is the p95 time from an add request until its memories can be found: 19 of every 20 requests finish within that time. It also depends on your provider and plan.
- Results from October 2026.
