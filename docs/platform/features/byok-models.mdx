## Set up BYOK

1. In the [Mem0 dashboard](https://app.mem0.ai/dashboard/settings?tab=org-llm), open **Settings → BYOK**.
2. Pick a provider: OpenAI, Anthropic, OpenRouter or Azure OpenAI.
3. Paste your API key and enter the model. On OpenRouter, use the model's full ID, such as `openai/gpt-5-mini`. Azure OpenAI also needs your endpoint URL and deployment name.
4. Click **Save provider**. Mem0 writes your memories with that model from then on. **Disable provider** switches back to Mem0's default model.

## How we tested

- Only the model that writes memories changes: extraction, temporal, categorization and summary all run on it.
- An LLM answers each question from the 200 memories Mem0 ranks highest (top_200), and an LLM judge grades it against LoCoMo's reference answer. Accuracy is averaged over two runs: the first, and a second that gives every question the model missed one more try. Search, answering and grading are the same for every model.
- Cost is estimated from each model's calls at list prices, per 1,000 LoCoMo adds (about 8 messages each).
- Latency is the p95 time from an add call until its memories are saved: 19 of every 20 adds are faster. Temporal and summary run after that, in the background. Adds that a provider's rate limit made Mem0 retry are left out: those depend on your provider and plan. Results from October 2026.
